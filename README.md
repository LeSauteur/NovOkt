## Запуск

Из `C:\Domian\NovOktPublish`:

```powershell
npm run dev
```

Локальный просмотр: http://127.0.0.1:4177/NovOkt/

```powershell
npm run build
npm run qa
git diff --check
```

Идентичность офиса: `assets/office.json`. Генератор: `scripts/build-place.mjs`.
Генерируемые страницы редактировать через генератор.

Объявления прежнего офиса удалены. Каталог показывает пустое состояние с предложением обсудить подбор. После получения подтверждённой базы объекты добавляются в `assets/js/place-data.js`. Избранное и сравнение используют отдельные ключи `novo-oktyabrsky:*`.

Калькуляторы, схема районов, сравнение районов и подготовка описания для продажи работают локально. Приём заявок и аналитика не подключены. Прямые контакты настоящие. Публикация: https://lesauteur.github.io/NovOkt/ — GitHub Pages из main. Демо закрыто от индексации до наполнения каталога; `robots.txt` и noindex сохранены.
